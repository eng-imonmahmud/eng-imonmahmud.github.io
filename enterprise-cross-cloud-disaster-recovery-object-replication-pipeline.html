# Enterprise Cross-Cloud Disaster Recovery & Automated Object Replication Pipeline ## Enterprise Architecture Overview This repository contains a production-quality, fully serverless, and event-driven data replication pipeline. The pipeline automatically replicates objects from Google Cloud Storage (GCP) to Amazon S3 (AWS) in near real-time, functioning as a robust Disaster Recovery (DR) solution. ### Business Problem Organizations face significant risks from data loss or regional cloud outages. Vendor lock-in also prevents seamless operations during critical failures. To meet strict RPO (Recovery Point Objective) and RTO (Recovery Time Objective) requirements, companies need multi-cloud disaster recovery strategies without incurring the high costs of constantly running compute instances. ### Solution This project implements an automated, serverless replication mechanism that bridges GCP and AWS. Leveraging event-driven architecture, the solution triggers only when new data is ingested, ensuring high availability, extreme cost-efficiency, and compliance with enterprise security standards. ## Key Features - **Fully Serverless & Event-Driven:** Built using Google Cloud Functions Gen2 and Eventarc. Zero idle compute costs. - **Cross-Cloud Replication:** Seamlessly transfers objects from Google Cloud Storage to Amazon S3. - **Enterprise Security (Least Privilege):** Strict IAM roles applied across both clouds. AWS Credentials are never exposed; they are injected dynamically at runtime via Google Secret Manager. - **Infrastructure as Code (IaC):** 100% automated provisioning and teardown using Terraform. - **Robust Error Handling & Logging:** Comprehensive observability via Google Cloud Logging. ## Technology Stack - **Cloud Providers:** Google Cloud Platform (GCP), Amazon Web Services (AWS) - **Infrastructure as Code:** Terraform - **Compute:** Cloud Functions (Gen2 / Cloud Run) - **Eventing:** Eventarc - **Storage:** Google Cloud Storage, Amazon S3 - **Security:** GCP Secret Manager, GCP IAM, AWS IAM - **Programming Language:** Python 3.11 ## Architecture Diagram ```mermaid flowchart TD classDef gcp fill:#4285F4,stroke:#fff,stroke-width:2px,color:#fff classDef aws fill:#FF9900,stroke:#fff,stroke-width:2px,color:#fff classDef secret fill:#0F9D58,stroke:#fff,stroke-width:2px,color:#fff subgraph "Google Cloud Platform (Primary)" GCS[("Google Cloud Storage\n(Source Bucket)")]:::gcp Eventarc["Eventarc Trigger\n(Object.Finalized)"]:::gcp CF["Cloud Function Gen2\n(Python 3.11)"]:::gcp SecretMgr["Secret Manager\n(AWS Credentials)"]:::secret CloudLog["Cloud Logging"]:::gcp end subgraph "Amazon Web Services (DR)" IAM["AWS IAM User\n(Least Privilege)"]:::aws S3[("Amazon S3\n(Destination Bucket)")]:::aws end GCS -- "1.
