# Enterprise Serverless API Gateway & Secure Microservices Architecture ## Project Description This project demonstrates a production-ready, highly secure, and automated Enterprise Serverless Architecture built natively on Google Cloud Platform (GCP). It features a Python Flask microservice containerized using Docker, continuously built via Google Cloud Build, and stored in Artifact Registry. The service is securely deployed to a private Google Cloud Run instance. To adhere to the Zero Trust security model, the Cloud Run instance strictly blocks all unauthenticated public access. Traffic is exclusively managed and routed through a Google Cloud API Gateway, which utilizes a dedicated Identity and Access Management (IAM) service account with least privilege permissions (`roles/run.invoker`) to authenticate and securely invoke the private backend. The entire pipeline, infrastructure deployment, IAM configuration, validation, and cleanup have been automated, eliminating the need for manual intervention and mitigating security risks. ## Architecture Overview The application traffic flows securely through the following path: **Internet** → **API Gateway** → **IAM Authentication (Service Account)** → **Private Cloud Run** ## Technology Stack * **Language**: Python 3.11 * **Web Framework**: Flask * **Containerization**: Docker * **CI/CD**: Google Cloud Build * **Container Registry**: Google Artifact Registry * **Serverless Compute**: Google Cloud Run (Private) * **API Management**: Google Cloud API Gateway * **Security & Auth**: Google Cloud IAM (Zero Trust, Least Privilege) * **API Specification**: OpenAPI 2.0 (Swagger) * **Scripting**: Bash / PowerShell ## Features * **Zero Trust Security Model**: Direct public access to the Cloud Run microservices is completely blocked using the `--no-allow-unauthenticated` policy. * **Least Privilege IAM**: The API Gateway uses a dedicated service account limited strictly to the `run.invoker` role. * **Automated CI/CD**: Seamlessly transitions from raw code to a deployed container image via Cloud Build and Artifact Registry. * **API Management**: Centralized routing and API specification using a fully managed Google API Gateway. * **Infrastructure as Code (IaC) principles**: Standardized deployment scripts and OpenAPI YAML for repeatable, immutable deployments. ## Security Model This project stringently enforces enterprise-grade security protocols: 1. **No Public Direct Access**: Attempting to bypass the Gateway and access Cloud Run directly results in a deliberate `403 Forbidden` response. 2. **Explicit IAM Binding**: Only the designated API Gateway Service Account possesses the precise cryptographic token authority to negotiate entry to the backend. 3. **Strict Git Ignore Policies**: All local JSON credential files, PEM keys, temporary artifacts, and environmental configuration files are systematically ignored to prevent credential leakage. ##
